The Donut Landers: Sugar Rush
==============================

A classic slot-machine cabinet style browser game styled after iconic arcade cabinets (CRÉDITO / PRÊMIO / APOSTA meters) and inspired by The Donut Landers universe.

FEATURES:
- 5 reels with 3 visible symbols per reel.
- Donut-themed symbols (coffee, glazed donuts, choco sprinkles, berry blast, lander characters, wilds, and jackpot stars).
- Arcade cabinet header display with red LED meters (CREDITO, PRÊMIO, APOSTA).
- Bottom jackpot progress indicators.
- 12 progressive levels with increasing stakes.
- Editable Symbol Workshop allowing you to change symbol names, image paths, and payouts without editing code.
- 8 Replaceable Audio Slots (synthesized Web Audio default with local MP3 support).
- 5-second startup splash screen and rectangular logo branding.
- Copyright footer: © Pixel Pop Games 2026 Donutland | The Donut Landers by Killer Art Media. www.TheDonutLanders.com

LOCAL RUNNING INSTRUCTIONS:
1. Extract this ZIP archive into a local folder.
2. Open `index.html` directly in any web browser.

GITHUB PAGES DEPLOYMENT:
1. Initialize git and commit:
   git init
   git add .
   git commit -m "Initial commit for The Donut Landers: Sugar Rush"
2. Push to GitHub:
   git remote add origin https://github.com/PixelPopGames/The-Donut-Landers-Sugar-Rush.git
   git branch -M main
   git push -u origin main
3. Enable GitHub Pages under Repository Settings -> Pages.

ASSET REPLACEMENT INSTRUCTIONS:
- Symbols: Replace SVG/PNG files in `assets/symbols/`
- Logos: Replace `assets/images/logo.svg` (1600x400) and `assets/images/splash-logo.svg` (1024x1024)
- Music: Place MP3 files in `assets/music/`
